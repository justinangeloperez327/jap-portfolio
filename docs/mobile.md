# Mobile UX

Mobile follows the same information hierarchy as desktop but does not force a desktop composition into a narrow viewport.

- Text-first Home hero and separate stacked blank scene frame
- Compact navigation with touch-accessible targets
- Responsive type and section spacing
- Text-first featured project cards
- Case studies with readable, sequential content and placeholder area
- Contact form controls that fill available width

There are no loaded images or image crop settings in the current version. Future scene layers must support a purpose-built mobile composition.
