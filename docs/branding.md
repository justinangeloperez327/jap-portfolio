# Branding

Brand identity values are configured in `data/brand.ts`.

The header and footer use the text-only **JAP** mark in `components/brand/brand-mark.tsx`. No SVG or raster logos are committed. The web manifest contains application metadata without icon assets.

There are no generated Apple touch icons or Open Graph preview images. Social cards use text metadata until branded imagery is approved.

New final branding assets can be integrated deliberately without altering navigation or layout contracts.
