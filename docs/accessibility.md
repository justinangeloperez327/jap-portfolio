# Accessibility

Content and navigation must work without visual assets, JavaScript motion, or a pointer.

- Use semantic headings, links, lists, navigation landmarks and labelled forms.
- Maintain keyboard-visible focus states, a skip-to-content link and large enough touch targets.
- Keep foreground/body contrast legible over dark background surfaces.
- Provide readable text instead of encoding information in color or artwork.
- Empty scene slots are decorative and hidden from assistive technologies.
- Honor `prefers-reduced-motion` and forced-colors preferences.
- Responsive layouts must reflow without horizontal scrolling or overlapping labels.
- Contact form errors must be actionable and announced appropriately.

When approved artwork is later integrated, reassess contrast, alt-text need (decorative vs. informative), load behavior, and reduced-motion alternatives for moving scenes.
